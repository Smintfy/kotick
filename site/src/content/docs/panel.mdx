## Machine list

The bubble opens the panel on the machine list. The header shows the path of the page and the number of machines. Each row shows the number of states of its machine. A row also shows `child` when all the instances of the machine are child actors, the number of instances when there is more than one, and a dot while an instance is previewed. While a preview is on, **Release all** at the bottom of the list releases every preview.

## Machine page

Select a machine to open its page. During a preview, the header shows the number of previewed states.

- **Instance** is a picker under the header, for a machine with more than one instance. A blue dot shows in the picker while the selected instance is previewed. For a machine with one instance, the `debug.label` of the instance shows in the same place, if it has one.
- **States** shows the state tree. Select a compound or parallel state to collapse or expand it. The marks after a leaf show the context that a preview of it uses: **R** is recorded context, **F** is a fixture, and **–** is none. During a preview, **Release** releases it. A child machine shows the name of its parent, and you cannot preview its states. A machine with child actors shows a **Children** row. Select a child to open its page.
- **Context** shows the context of the instance. During a preview, select its source: **Recorded**, **Fixture** or **Live**.
- **Blocked events** lists the events that the UI sent during a preview, for all the instances on the page. An event from a different instance shows the name of that instance. The same event sent again right after shows once, with a count. Select an event to see the state, the instance, the times and the payload. **Clear** removes all the events from the list.
- **Copy JSON** copies the state of the instance.

**Back** goes to the machine list again.

## Settings

**Settings**, at the bottom of the list, moves the bubble and the panel to another corner, and lists the keyboard shortcuts.

## Keyboard

| Keys | Where | Action |
|---|---|---|
| <Shortcut mac="⌥S" other={['Alt', 'S']} /> | Anywhere | Open or close the panel |
| <Kbd>↑</Kbd> / <Kbd>↓</Kbd> | Machine list | Go to the previous or next row |
| <Shortcut mac="⌘↑" other={['Home']} /> / <Shortcut mac="⌘↓" other={['End']} /> | Machine list | Go to the first or last row |
| <Kbd>↑</Kbd> / <Kbd>↓</Kbd> | Machine page | Go to the previous or next state |
| <Shortcut mac="⌘↑" other={['Home']} /> / <Shortcut mac="⌘↓" other={['End']} /> | Machine page | Go to the first or last state |
| <Kbd>Enter</Kbd> | Machine page | Preview or release the state |
| <Kbd>[</Kbd> / <Kbd>]</Kbd> | Machine page | Go to the previous or next machine |
| <Kbd>Esc</Kbd> | Panel | Release all previews |

The table shows the keys for your system. On macOS, <Kbd>Home</Kbd> and <Kbd>End</Kbd> also work. The shortcuts do nothing while you type in an input, a text area or an editable element. To change the toggle shortcut, set `shortcut`.
