## My machine is not in the panel. Why?

The panel lists only the machines that an adapter registers. [A machine is missing from the panel](/docs/troubleshooting#a-machine-is-missing-from-the-panel) lists the causes and their fixes.

## Can a preview change my data or call my API?

Only through your components. During a preview, kotick blocks the events that the UI sends, and the machine does not run the effects of the previewed state. The real machine continues to run, with its own effects. Effects in your components do run for the previewed state. So a `useEffect` that fetches when a state shows also fetches when you preview that state.

## Why does a preview show the wrong data?

For an XState machine, the state had no recording and no fixture, so the preview uses the live context. The console shows a warning, and the state tree marks the state. Visit the state once in the real app, or write a [fixture](/docs/fixtures) for it.

A reducer machine does not use the live context for another state. The panel greys out such a state until it has a recording or a fixture.

## Does it work with React 18 and StrictMode?

Yes. The test suite runs on React 18 and 19, with StrictMode on.

## Does it work with `useReducer`?

Yes, through `kotick/reducer`. Declare the reducer as a machine that names each state, and call `useMachineReducer` instead of `useReducer`. See [Reducer machines](/docs/reducer).

## Does it work with Zustand or other state libraries?

No. kotick lists the states in the machine definition, including the states that you have not visited. So it needs a machine that declares its states, as reducer machines and XState machines do.

## Does it work with XState v4 or v6?

No. It works with XState v5 only.

## Can I use it in a staging or preview build?

No. kotick is a development tool. Staging and preview builds are usually production builds, and `<Kotick />` renders nothing in a production build.

## Two copies of kotick are in my bundle. Is that a problem?

No. All copies use one registry on `globalThis`. If the versions are different, the console shows a warning.
