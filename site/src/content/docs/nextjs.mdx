Both entries start with `'use client'`, so you can import them in the App Router.

- A server component can render `<Konat />`, for example in the root layout.
- A server component cannot give a function to a client component, so it cannot give the `fixtures` loader. Render `<Konat fixtures={…} />` in a client component, and render that component in the layout:

  ```tsx
  // src/components/dev-tools.tsx
  'use client';

  import { Konat } from 'konat';

  const fixtures = process.env.NODE_ENV !== 'production' ? () => import('@/debug/fixtures') : undefined;

  export function DevTools() {
    return <Konat fixtures={fixtures} />;
  }
  ```

- Call the hooks and `createActorContext()` only in client components, as with `@xstate/react`.
- On the server, konat does nothing: the overlay renders nothing, and nothing registers. The overlay mounts after hydration, so it does not cause hydration errors.

In a monorepo that gives the TypeScript source of konat, add it to `transpilePackages`.
